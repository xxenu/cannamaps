# Shops on the same location

Pins within **40 m** of each other — usually one premises that
changed name. Decide which to keep, then delete the other by `id`.

Signals, strongest first:

- **greenmeister** — `no` means the up-to-date directory no longer lists it. Strongest hint it is defunct.
- **status** — `closed` is coffeeshopmenus.org saying so outright.
- **latest menu** — when its last menu was posted. An old date next to a recent one is decisive.
- **note** — the source sometimes names the successor outright.
